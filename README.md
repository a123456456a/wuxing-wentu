# 问道 · 山河试炼

原创的单机回合制修仙小游戏。气氛参考经典 2D 回合制修仙网游，但门派、法术、地图、灵兽和界面都是新写的，不使用任何商业作品的图像、标志或原文设定。

## 怎么运行

需要 Node.js 18 或更高版本。

```bash
npm install
npm run dev
```

浏览器打开 [http://127.0.0.1:43123](http://127.0.0.1:43123)。

```bash
npm run build
npm run preview
```

`build` 会做类型检查并把可玩版本放到 `dist/`。`preview` 默认开在 43129 端口。

## 玩什么

1. 起名，选一个门派，再选五行亲和。门派决定法术，亲和决定普通攻击，同属性法术也会更有力。
2. 在青石村找客栈调息、铁铺买装备、灵兽苑领第一只同伴，向南出村。
3. 点击地面行走，或用 WASD / 方向键。手机可以用右下角方向键。
4. 高草可能遇敌，发光的妖气一定会开战。战斗是你和一只灵兽对怪物的回合制。
5. 五行相克会提高伤害和控制成功率；相生会泄掉一点伤害，并收回少许法力。
6. 胜利增加等级、金钱和道行。道行越高，法术越稳，也越不容易被冻住或封招。
7. 气血残的幼兽可以用契灵符结契。青藤灵鹿只在忘机林出现。
8. 玄霜洞底有一场头目战。进度写在浏览器的 localStorage 里，刷新后还能继续。

## 功能

- 五个原创门派：青岚剑宗、赤霞火府、玄溟水榭、厚土禅院、青木药谷
- 五行亲和，以及相生相克
- 四块相连地图：青石村、落霞野、忘机林、玄霜洞
- 回合战斗：攻击、法术、物品、防御、契灵、撤退，灵兽也可手动下令
- 四种灵兽，可招募或捕捉，只能携带一只出战
- 等级、金钱、武器和衣服
- 道行
- 本地存档

## 已知限制

- 只有单人，没有服务器，也没有其他玩家。
- 地图很小，怪物种类有限，适合玩十几分钟。
- 战斗进行到一半时刷新页面，会回到最近一次存档，不会停在半场战斗里。
- 每种灵兽只能拥有一只。
- 画面是几何色块，不是像素原画。
- 工程自带 TypeScript 编译器和一份只实现了本游戏所用接口的 React 运行时，因此 `npm install` 不需要访问外网。

## 技术说明

`npm run dev` 会启动 TypeScript 监听编译，并用 Node 静态服务打开页面。入口是 `index.html`，游戏逻辑在 `src/game`，界面在 `src/ui`。
