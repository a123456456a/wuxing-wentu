# 五行问途

原创的单机回合制修仙小游戏。气氛参考经典 2D 回合制修仙网游，但门派、法术、地图、灵兽和界面都是新写的，不使用任何商业作品的图像、标志或原文设定。

## 怎么运行

需要 Node.js 18 或更高版本。

```bash
npm install
npm run dev
```

浏览器打开 [http://127.0.0.1:43123](http://127.0.0.1:43123)。

```bash
npm run build
npm run preview
```

`npm run build` 会做类型检查，并把可玩版本放到 `dist/`。`npm run preview` 默认开在 43129 端口。

## 功能

- 创角：起名，五个原创门派（青岚剑宗、赤霞火府、玄溟水榭、厚土禅院、青木药谷），再选五行亲和
- 五行相生相克：相克提高伤害和控制成功率，相生会泄掉一点伤害并收回少许法力
- 四块相连地图：青石村、落霞野、忘机林、玄霜洞。点击地面或 WASD / 方向键移动，手机可用方向键
- 回合战斗：你和一只出战灵兽对怪物。指令有攻击、法术、物品、防御、契灵、撤退
- 四种灵兽：焰尾灵狐、墨纹幼蛟、岩背玄龟可在村里招募，青藤灵鹿要在忘机林用契灵符捕捉
- 成长：等级、金钱、道行、武器和衣服。道行越高，法术越稳，也越不容易被控制
- 本地存档：进度写在浏览器 localStorage，刷新后可以继续

## 玩法提示

1. 在青石村找客栈调息、铁铺买装备、灵兽苑领第一只同伴，向南出村。
2. 高草可能遇敌，发光的妖气一定会开战。
3. 玄霜洞比外面凶。不到 6 级时，洞口会先提醒你。
4. 战斗进行到一半时刷新页面，会回到最近一次存档。

## 已知限制

- 只有单人，没有服务器，也没有其他玩家。
- 地图很小，怪物种类有限，适合玩十几分钟。
- 每种灵兽只能拥有一只。
- 画面是原创的工笔 / 水墨风界面和几何立绘，不是商业游戏的像素原画。
- 工程自带 TypeScript 编译器和一份只实现了本游戏所用接口的 React 运行时，因此 `npm install` 不需要访问外网。正文字体随仓库附带，见下方「画面」。

## 画面

界面按宣纸、木框、描金和朱印来组织，地图与战斗背景画了远山、流云和亭檐。这些图形都是为本作新画的，不使用《问道》或其他商业作品的图像、标志、字体或界面零件。

| | 之前 | 现在 |
| --- | --- | --- |
| 字体 | 系统无衬线黑体 | 内置 Noto Serif SC 简体（SIL Open Font License，见 `vendor/fonts/OFL.txt`） |
| 面板 | 圆角浅色卡片 | 宣纸底、木色描金边、朱印 |
| 标题 / 创角 | 纯色渐变上的文字 | 水墨远山与流云前的立轴 |
| 地图 | 平涂方块和三角小人 | 远山、云、水纹、亭台、带发髻的人物 |
| 战斗 | 上下两截色带 | 原创水墨山水底，墨线肖像立牌 |

字体文件是 Fontsource 发布的 Noto Serif SC `chinese-simplified` 400 / 700 woff2，运行时从本仓库读取，不请求外部 CDN。

## 技术说明

`npm run dev` 会启动 TypeScript 监听编译，并用 Node 静态服务打开页面。入口是 `index.html`，游戏逻辑在 `src/game`，界面在 `src/ui`。
